# Indie Film Collective Website

A multi-page, responsive website built for the **Indie Film Collective**, a creative community dedicated to independent filmmakers, storytellers, and visual artists.

## Project Overview
This project consists of four interconnected pages designed to showcase independent film screenings, educational workshops, networking collaborations, and festival volunteer opportunities.

- **`index.html`** - Homepage introducing the collective and upcoming festival news.
- **`screenings.html`** - Details on upcoming film showcases and schedules.
- **`workshops.html`** - Overview of hands-on training tracks and learning modules.
- **`collaborations.html`** - Information on creative networking mixers and community testimonials.

## Features & Technical Stack
- **Languages:** HTML5, CSS3
- **Layout & Design:** Mobile-first approach utilizing CSS Grid and media queries (optimized for screens 800px and wider).
- **Accessibility:** Semantic HTML5 elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<aside>`, `<footer>`) and descriptive image `alt` text.
- **Version Control:** Managed via Git, VS Code, and GitHub Desktop.
